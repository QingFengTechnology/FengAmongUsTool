# 清风工具箱

清风工具箱是一个简洁而优雅的 Among Us 工具箱，只需点击几下即可方便的安装 Among Us 私服、切换 Among Us 版本配置。

> [!Note]
> v4 版本仍在 alpha 阶段，欢迎各位提出反馈与做出贡献。
